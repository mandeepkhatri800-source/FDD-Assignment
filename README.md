# LBEF/APU Student Hackathon Website 2026

Official student technology hackathon portal representing the academic collaboration between Lord Buddha Education Foundation (LBEF) in Kathmandu, Nepal, and Asia Pacific University of Technology & Innovation (APU) in Kuala Lumpur, Malaysia.

This project is designed as an undergraduate coursework assessment for the **Fundamentals of Web Design and Development (FDD)** module.

## Technologies Used
- **Structure**: HTML5 (Semantic elements)
- **Styling**: CSS3 (CSS Variables, Grid, Flexbox, Media Queries)
- **Interactions**: Vanilla JavaScript (no external libraries or frameworks)

## Key Interactivity Features
1. **Responsive Mobile Menu**: Hamburger menu toggling using vanilla JavaScript.
2. **Countdown Timer**: Real-time event countdown calculated client-side.
3. **Challenge Category Filtering**: Dynamic cards filter matching category tags.
4. **Registration Validation**: Detailed frontend validation check of fields, emails, size constraints, and terms agreement.
5. **FAQ Accordion**: Single-item active accordion expansion.
6. **Gallery Lightbox Modal**: Custom modal opening and overlay close handlers.
7. **Form Validation Confirmations**: Client-side success notices for contact and feedback.
